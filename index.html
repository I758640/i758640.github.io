AI-First Design Enterprise UX 01

Joule Studio 1.0 → 2.0
Migration Experience

Users needed to migrate solutions between Joule Studio versions, but the process involved complex technical decisions, multiple states, and no clear guidance. The system needed to feel intelligent — not intimidating.

Role UX Designer — user flows, IA, AI-first interaction model, migration dashboard, readiness experience & error states
Focus Conversational UX · Migration Readiness · Error Recovery · State Communication
Designed an AI-first migration experience guiding users through every step — communicating readiness, progress, and next actions — reducing cognitive load in a high-stakes workflow.

Interaction Design Data Management 02

Execution Monitoring
& Mass Actions

Managing hundreds of execution instances required more than a table. Users needed to understand state, act in bulk, handle API constraints gracefully, and recover from failures — all in one coherent experience.

Role UX Designer — IA, interaction design, mass-action flows, action states, error handling, tooltips, dialogs & UX copy
Focus Bulk Selection · API Limit Handling · Retry Flows · State Design · Contextual Guidance
Designed comprehensive bulk-management patterns including Select All, 100-instance API limits, retry flows, disabled states, and guidance for Retry, Resume, Suspend, Restart, and Cancel.

UX Research Usability Testing 03

Joule Studio Usability Testing

The conversational interface was live — but was it actually working? We needed to understand how users naturally approached agent creation and whether the experience communicated the right things at the right moments.

Role UX Designer / UX Research Specialist — test planning, user observation, synthesis, insight generation & design recommendations
Methods Moderated usability sessions · Think-aloud protocol · Affinity mapping · Prioritized design recommendations
Surfaced actionable insights that improved navigation patterns, conversational content clarity, and the overall agent-creation flow — closing the gap between design intent and user reality.
